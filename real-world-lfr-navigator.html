How to Use

  1. Desktop testing (recommended first step): Click "Load Demo (~200m North)" in the blue test panel above, then click START AUDIO. You should hear sound immediately and see telemetry update.
  2. Use the quick offset buttons (N/S/E/W) to move your test position around the beacon and hear how the A/N signals change.
  3. iOS / real GPS: Tap START, allow location, then walk or drive. Make sure Precise Location is enabled in Settings → Privacy → Location Services → [Browser].
  4. Adjust beacon altitude (negative for ground tests), max range, and cone angle live — everything updates in real time.
  5. Cone of Silence: When you are nearly overhead (within the cone angle), volume fades to zero. This is the classic station passage cue.
  6. Steady tone: When you are on one of the four beams, A and N overlap perfectly → continuous tone with no gaps.

Note: Phone GPS altitude is often inaccurate (±10–30 m). For real aircraft use, feed better altitude data if possible.
